# Licensing

This repository uses a professional multi-license structure. Each file is
licensed according to its category below. SPDX identifiers are authoritative.

| Category | License | Applies to |
| --- | --- | --- |
| Hardware design | CERN-OHL-S-2.0 | `homelab_rack.scad`, generated `.stl` and `.3mf` hardware artifacts, and CAD geometry exported from that source |
| Software and tooling | MIT | PowerShell, Python, TypeScript, JavaScript, CSS, HTML, workflow/configuration files, and the viewer application |
| Documentation and media | CC-BY-4.0 | Markdown/text documentation and rendered `.png` images |

Exact license texts are provided in:

- [`LICENSES/CERN-OHL-S-2.0.txt`](LICENSES/CERN-OHL-S-2.0.txt)
- [`LICENSES/MIT.txt`](LICENSES/MIT.txt)
- [`LICENSES/CC-BY-4.0.txt`](LICENSES/CC-BY-4.0.txt)

Binary artifacts are not modified merely to embed license metadata. Their
license is established by this mapping. Third-party dependencies retain their
own licenses.
