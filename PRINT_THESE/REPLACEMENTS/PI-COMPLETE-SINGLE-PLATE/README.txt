PI COMPLETE SINGLE-PLATE A1 PROJECT
===================================

Print this project for all remaining Pi hardware:

  homelab-rack-Pi-Complete-Single-Plate-A1.3mf

It contains exactly:

  1. 04_Dual_Pi_Chassis_5mm_HAT_Clearance.stl
  2. 05_Pi_Drawer_1_6mm_Magnet_Fit.stl
  3. 06_Pi_Drawer_2_6mm_Magnet_Fit.stl

The vent is intentionally excluded because it has already been printed.
No existing replacement STL or project is modified by this package.

The chassis retains its validated orientation and two build-plate-only manual
support strips beneath the raised outer Pi-bay front rails. Both strips are
open to the front and can be removed from outside the empty chassis before
installing the drawers. No support reaches either drawer.

The drawers are rotated only around Z while remaining on their validated
support-free print faces. Their bounding boxes have 7.20 mm horizontal
clearance. The nearest chassis-to-drawer clearance is 9.60 mm.

Pinned native Bambu Studio 02.08.02.61 A1 estimate:

  Material: 143.52 g PLA
  Time:     6h27m32s
  Bridge:   17.52 mm maximum classified span

The native reopen/reslice reproduced 143.52 g and the same bridge maximum
without warnings; Bambu recalculated the time as 6h27m19s.
